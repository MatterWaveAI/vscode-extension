# Edit in place

Select the lines to change and run **MatterWave: Edit Selection with MatterWave** (`Ctrl+I` / `Cmd+I` where no other inline chat has it, or `Ctrl+Alt+M I`; `Ctrl+Cmd+M I` on macOS). Say what should change; the answer comes back as a diff of those lines, with their indentation kept, and lands only when you apply it.

In a workspace you have not trusted, editing waits until you trust it.
