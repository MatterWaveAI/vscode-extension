# Ask about a selection

Select some code, then run **MatterWave: Ask about Selection** (also on the editor's context menu, or `Ctrl+Alt+M A`; `Ctrl+Cmd+M A` on macOS). The selection goes with your question, fenced with its language and its path in the workspace.

In the chat view's composer, `@file`, `@folder`, `@terminal`, `@git` and `@docs` attach more context, and `/` runs a command or one of your saved prompts.
